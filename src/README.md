# src/ - search engines and shared C code

This directory contains the compiled search engines and shared implementation
modules.

## Layout

| Path | Purpose |
|---|---|
| `cuda/` | Production CUDA engine (`kt_filter_v8`) and oracle engine (`kt_filter_v5`) |
| `cpu/` | CPU/GMP reference and low-volume search engine (`kt_search`) |
| `common/` | Shared pattern catalog, JSON parser, and verification helpers |

## Build Entry Points

```bash
# GPU engine
cd src/cuda
make kt_filter_v8

# CPU engine
make -C src/cpu
```

## Documentation

| File | Purpose |
|---|---|
| `cuda/README.md` | CUDA engine modules, features, and build commands |
| `cpu/README.md` | CPU engine status and implementation notes |
| `cpu/HOWTO_RUN.md` | CPU build/run examples |
| `../HOWTO.md` | Main GPU operating guide |
| `../docs/CUDA_CLI_REFERENCE.md` | Long-form CUDA CLI reference, including `--wheel-expr` |

The generated pattern catalog lives in `common/ktuplet_pattern.{h,c}` and is
regenerated by `python3 tools/gen_pattern_header.py`.
